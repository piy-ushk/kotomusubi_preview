Chapter 4-1 ・ 初級しょきゅう Beginner

あります・います

There is / There are ／ 物もの・人ひとの 存在そんざいを 言おういおう

考えかんがえてみよう ／ Let's think first

次つぎの 文ぶんを 読んよんでください。

机つくえの 上うえに 本ほんが あります。

There is a book on the desk.

公園こうえんに 猫ねこが います。

There is a cat in the park.

部屋へやに テレビが あります。

There is a TV in the room.

教室きょうしつに 先生せんせいが います。

There is a teacher in the classroom.

「あります」と「います」の 違いちがいは 何なにだと 思いおもいますか？

What do you think is the difference between「あります」and「います」?

ヒント：「あります」と「います」の 前まえの名詞めいし に 注目ちゅうもくしてください。

「あります」は 物もの・場所ばしょ（動かうごかない物もの）に、「います」は 人ひと・動物どうぶつ（動くうごく物もの）に 使いつかいます。

「あります」is for things and places (that don't move), and「います」is for people and animals (that can move).

1意味いみ ／ Meaning

「あります」と「います」は どちらも 「There is / There are」を表しあらわします。
でも、使い分けつかいわけが 大事だいじです：
「あります」は 物もの・場所ばしょに、
「います」は 人ひと・動物どうぶつ に使いつかいます。

Both「あります」and「います」mean "there is / there are".
But they're used differently:
「あります」for things and places,
「います」for people and animals.

あります things / places

物もの・場所ばしょ・自然しぜんの物もの（本ほん・机つくえ・建物たてもの・山やま・川かわなど）。動かうごかない物もの。

  • 机つくえの 上うえに 本ほんが あります。
  • 近くちかくに スーパーが あります。

Used for things, places, and natural objects (books, desks, buildings, mountains, rivers, etc.) — things that don't move.

There is a book on the desk.
There is a supermarket nearby.

います people / animals

人ひと・動物どうぶつ・キャラクター（先生せんせい・友達ともだち・猫ねこ・犬いぬ・ポケモンなど）。動けるうごける物もの。

  • 公園こうえんに 猫ねこが います。
  • 教室きょうしつに 学生がくせいが います。

Used for people, animals, and characters (teachers, friends, cats, dogs, Pokémon, etc.) — things that can move.

There is a cat in the park.
There are students in the classroom.

2文型ぶんけい ／ Sentence Pattern

基本きほんの形かたち：場所ばしょ に 名詞めいし が あります／います

場所ばしょ に 名詞めいし が 動詞どうし
机つくえの上うえ に 本ほん が あります
公園こうえん に 猫ねこ が います
部屋へや に テレビ が あります

Basic pattern: [Place] + に + [Noun] + が + あります／います = "There is/are [Noun] in [Place]."

PlaceにNounがVerb
on the deskにbookがあります
parkにcatがいます
roomにTVがあります

あります と います の 文ぶんの形かたち

文ぶんの形かたちは 同じおなじです。

場所ばしょ ＋ に ＋ 名詞めいし ＋ が ＋ あります／います

  • 人ひと・動物どうぶつ → います
  • もの・植物しょくぶつ → あります

The sentence pattern is the same: [place] に [noun] が あります／います. Use います for people and animals, and あります for things and plants.

間違えまちがえやすいポイント

× bad✅ good
猫ねこが あります。猫ねこが います。
椅子いすが います。椅子いすが あります。
先生せんせいが あります。先生せんせいが います。

猫ねこ (cat) is an animal → use います, not あります.
椅子いす (chair) is a thing → use あります, not います.
先生せんせい (teacher) is a person → use います, not あります.

否定ひてい形けい ／ Negative

肯定こうてい / affirmative否定ひてい / negative
ありますありません
いますいません

あります → ありません (there is → there isn't: things)
います → いません (there is → there isn't: people and animals)

答えこたえ方かた ／ How to answer

Q：本ほんが ありますか？　A：いいえ、ありません。

Q: Is there a book? A: No, there isn't.

Q：猫ねこが いますか？　A：いいえ、いません。

Q: Is there a cat? A: No, there isn't.

よく使うつかう「場所ばしょのことば」

「？」を 押すおすと 訳やくが 出でます。もう一いち度ど 押すおすと 隠れかくれます。

  • ここ？here
  • 右みぎ？to the right of
  • そこ？there (near you)
  • 左ひだり？to the left of
  • あそこ？over there
  • 近くちかく？near
  • 上うえ？on / above
  • 隣となり？next to
  • 下した？under
  • 前まえ？in front of
  • 中なか？inside
  • 後ろうしろ？behind
  • 間あいだ？between (A は B と C の 間あいだ)

3例文れいぶん ／ Example Sentences

家いえの 近くちかくに スーパーが あります。

There is a supermarket near my house.

母ははは 家いえに いません。

My mother is not at home.

今日きょうは 時間じかんが ありません。

I don't have time today.

父ちちと 妹いもうとの 間あいだに 犬いぬが います。

There is a dog between my father and my younger sister.

4ポイント ／ Key Points

  • 質問しつもんは「どこに〜ますか？」。
    「どこに ありますか？／いますか？」で 「Where is ~?」。「何なにが」「だれが」も よく使いつかいます。

    For questions: 「どこに〜ますか？」.
    「どこに ありますか／いますか？」asks "Where is ~?". Also use 「何なにが」"what" and「だれが」"who".

    例れい：トイレは どこに ありますか？／ 先生せんせいは どこに いますか？／ 何なにが ありますか？

    Where is the toilet? ／ Where is the teacher? ／ What is there?
