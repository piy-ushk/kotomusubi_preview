Chapter 13-5 ・ 中ちゅう上級じょうきゅう Upper-intermediate

〜なら

As for ~ / If it's ~ ／ テーマをしぼって話すはなす・くわしく答えるこたえる

1意味いみ ／ Meaning

「〜なら」は、「〜については」の意味いみです。
話題わだいを一ひとつえらんで、その話はなしだけをします。
「犬いぬなら、好きすきです」＝ほかの動物どうぶつはあまり好きすきじゃないけど、犬いぬは好きすきです。
「全部ぜんぶはできないけど、これならできる」と言いいいたいときや、
「音楽おんがくなら、このアプリがいいです」のようなアドバイスにも、よく使いつかいます。

「〜なら」 means "as for ~" / "if we're talking about ~".
You pick one topic and talk only about that.
「犬いぬなら、好きすきです」 = I don't really like other animals, but dogs, I like.
Use it when you want to say "I can't do everything, but this I can do,"
or to give advice like 「音楽おんがくなら、このアプリがいいです」 (For music, this app is good).

2文型ぶんけい ／ Sentence Pattern

形かたち意味いみ・例れい
名詞めいし ＋ ならnoun + nara「〜について 言ういうと」
（話題わだいをしぼる）サッカーならよく見みます
名詞めいし ＋ なら
＋ できる／わかるif it's ~, I can		「それなら できる・わかる」

＋ アドバイスif it's ~, you should		「〜なら、〜が いいよ」とすすめるひまなら、一緒いっしょに行きいきませんか？
動詞どうし（辞書じしょ形けい）＋ ならverb + nara「もし〜するなら」

FormMeaning / Example
noun ＋ ならas for ~ (speaking of)As for soccer, I watch it a lot.
noun ＋ なら ＋ can do／understandin that case, I can (it's possible)If it's a simple dish, I can make it.If it's kanji, I understand a little.

＊「〜なら」は、名詞めいしやフレーズ全体ぜんたいに付けつけます。
＊動詞どうしは 辞書じしょ形けい + なら。「ます形けい」には付けつけません（×食べたべますなら → ○食べるたべるなら）。

＊「〜なら」attaches to nouns or whole phrases.
＊For verbs: dictionary form + なら. Not the ます-form (×食べたべますなら → ○食べるたべるなら).

3例文れいぶん ／ Example Sentences

日本にほんのアニメなら、よく見みます。ドラマはあまり見みません。

As for Japanese anime, I watch it a lot. As for dramas, not so much.

簡単かんたんな料理りょうりなら、作れつくれますよ。カレーや パスタです。

When it comes to simple dishes, I can make them, like curry or pasta.

ひらがななら書けかけます。でも漢字かんじはまだ勉強べんきょう中ちゅうです。

As for hiragana, I can write them, but I'm still learning kanji.

スマホなら使えつかえます。パソコンは難しいむずかしいです。

I can use a smartphone. A computer is hard for me.

パスタなら、駅前えきまえのイタリアンがいいですよ。

As for pasta, the Italian place near the station is good.

ひまなら、一緒いっしょに映画えいがを見みませんか？

If you're free, why don't we watch a movie together?

飲むのむなら、お茶ちゃがいいです。

If I'm going to drink, tea is good.

4ポイント ／ Key Points

  • 「Aはできるけど、Bはできない」と比べるくらべることができる。 英語えいごなら少しすこし話せはなせます。中国ちゅうごく語ごは話せはなせません。
    和食わしょくなら得意とくいです。フランス料理りょうりは苦手にがてです。

    I can speak a little English, but I can't speak Chinese.
    I'm good at Japanese food, but not at French cooking.

    You can compare what you can and can't do.
    As for smartphones, I can use them; computers are hard.
    As for hiragana, I can read it; kanji not yet.

  • 「〜なら、〜がいいよ」とアドバイス・おすすめが できる。 ケーキが食べたべたいなら、あのお店みせがおすすめだよ。
    時間じかんがあるなら、一緒いっしょに行かいかない？

    If you want cake, I recommend that shop.
    If you have time, want to go together?

    You can give advice or a recommendation.
    If you want pasta, the shop by the station is good.
    If you're free, want to go together?

よくあるミスCommon mistakes

× 食べたべますなら、すしがすきです。
○ 食べるたべるなら、すしがいいです。
動詞どうしは「辞書じしょ形けい＋なら」。「ます形けい」には付きつきません。

Verbs use dictionary form + なら, never masu-form + なら.

Which do you like better, movies or dramas?

What do you know about Japanese culture?

As for anime and manga, I know them well. I'm still learning about tea ceremony and ikebana culture.
