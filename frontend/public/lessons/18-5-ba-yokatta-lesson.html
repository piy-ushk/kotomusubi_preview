Chapter 18-5 ・ 中ちゅう上級じょうきゅう Upper-intermediate

〜ばよかったです

Should have done ~ ／ 過去かこの後悔こうかいを伝えるつたえる

1意味いみ ／ Meaning

「〜ばよかったです」は、
過去かこの後悔こうかい・反省はんせい・「〜しておけばよかった」という願望がんぼうを表しあらわします。
「もっと勉強べんきょうすればよかった」「あんなに食べたべなければよかった」のように、
済んすんだことに対したいして、別べつの選択せんたくをしておくべきだったと振り返るふりかえるときに使いつかいます。

「〜ばよかったです」 expresses
regret about the past — "I should have done ~ / I wish I had ~".
Used when reflecting on a past choice
and wishing you'd done differently.

2文型ぶんけい ／ Sentence Pattern

動詞どうしのば形けい ＋ よかったです

グループ普通ふつう形けいば形けい（肯定こうてい）
1グループu→e + ば行くいく・買うかう・待つまつ行けいけば／買えかえば／待てまてば
2グループる→れば食べるたべる・見るみる食べれたべれば／見れみれば
3グループirregularする・くるすれば／くれば
groupplain formば-form (affirmative)
Group 1u→e + ば行くいく・買うかう・待つまつ(to go / to buy / to wait)行けいけば／買えかえば／待てまてば(if I go / if I buy / if I wait)
Group 2る→れば食べるたべる・見るみる(to eat / to see)食べれたべれば／見れみれば(if I eat / if I see)
Group 3irregularする・くる(to do / to come)すれば／くれば(if I do / if I come)

否定ひてい形けい：ない形けい →「い」を取っとって＋ ければ

グループ否定ひてい形けいば形けい（否定ひてい）
1グループ行かいかない／買わかわない行かいかなければ／買わかわなければ
2グループ食べたべない／見みない食べたべなければ／見みなければ
3グループしない／こないしなければ／こなければ
groupnegative formば-form (negative)
Group 1行かいかない／買わかわない(not go / not buy)行かいかなければ／買わかわなければ(if I don't go / if I don't buy)
Group 2食べたべない／見みない(not eat / not see)食べたべなければ／見みなければ(if I don't eat / if I don't see)
Group 3しない／こない(not do / not come)しなければ／こなければ(if I don't do / if I don't come)

＊ ば形けいに「よかったです」をつける。文末ぶんまつは常つねに 過去かこ形けい（よかった）。
＊ カジュアル：「〜ばよかった（です省略しょうりゃく）」「〜ばよかったね」

＊Add 「よかったです」to the ば-form; the sentence always ends in the past (よかった).
＊Casual: 「〜ばよかった」(drop です) ／ 「〜ばよかったね」.

4ポイント ／ Key Points

  • 過去かこのことだけ。
    「〜ばよかった」は、もう終わっおわったことを振り返るふりかえるときの言いいい方かた。未来みらいの願望がんぼうには使えつかえません。

    For past things only.
    Only for past events. Cannot express future wishes — use 「〜といい」 for those.

    × 明日あした、雨あめが降れふればよかったです。
    ○ 明日あした、雨あめが降るふるといいですね。

    ✗ ばよかった is for past regret, not the future
    ◯ for a future hope, use 〜といい

  • 肯定こうてい → 「〜ばよかった」／否定ひてい → 「〜なければよかった」。
    「やればよかった」＝ するべきだった（しなかったのを後悔こうかい）
    「やらなければよかった」＝ しなければよかった（してしまったことを後悔こうかい）。

    Affirmative → 「〜ばよかった」 ／ negative → 「〜なければよかった」.
    Affirmative = regret for NOT doing something.
    Negative = regret for HAVING done something.

    勉強べんきょうすればよかった ＝ 勉強べんきょうしなくて後悔こうかい
    食べたべなければよかった ＝ 食べたべたことを後悔こうかい

    "I should have studied" ― regret not doing it
    "I shouldn't have eaten" ― regret doing it

  • カジュアルでは「です」を省略しょうりゃく。
    友達ともだちとの会話かいわでは 「〜ばよかった」「〜ばよかったね」 もよく使いつかいます。

    In casual speech, drop the 「です」.
    In casual speech, drop 「です」 → 「〜ばよかった／〜ばよかったね」.

    もっと早くはやく起きれおきればよかったな。／買っかっておけばよかったね。

    I should have gotten up earlier. ／ I should have bought it.

  • 他ほかの人ひとについて言ういうときは「〜ばよかったね」。
    「あなた／彼かれ／彼女かのじょは〜ばよかったね」と、相手あいての行動こうどうを残念ざんねんがる言いいい方かた。

    When talking about someone else, use 「〜ばよかったね」.
    When directed at someone else: 「〜ばよかったね」 = "you should have ~".

    もっと早くはやく言っいってくれればよかったね。

    You should have told me sooner.

よくあるミスCommon mistakes

× 週末しゅうまつ、天気てんきがよければよかったです。
○ 週末しゅうまつ、天気てんきがいいといいですね。
「〜ばよかった」は過去かこの後悔こうかい専用せんよう。未来みらいの願望がんぼうは「〜といい」「〜たらいい」を使いつかいます。

「〜ばよかった」 is only for regrets about the past. For future hopes, use 「〜といい」「〜たらいい」.

🧒🏻 アナそれは焦るあせるね。
でもケン、ちゃんと入れはいれたならよかったじゃん。

That sounds stressful. But good that you made it in time at least.

👦🏻 ケンうん。でもね〜、もっと近いちかい席せきを買っかっておけばよかった。
後ろうしろのほうで、ほとんど顔かおが見えみえなかった。

Yeah. But you know, I should have bought a closer seat. I was so far back I could barely see their faces.

🧒🏻 アナあはは。次つぎは一緒いっしょに行こういこうよ！
早めはやめにチケットが取れとれるといいね！

Haha. Let's go together next time! I hope we can get tickets early!

👦🏻 ケンうん、絶対ぜったいそうする。
あんなに後悔こうかいしたのは久しひさしぶりだったよ。

Yeah, definitely. I haven't felt that much regret in a while.

🧒🏻 アナ私わたしも。ずっと家いえでゴロゴロしていたから…行けいけばよかった！

Me too. I was just lazing around at home the whole time… I should have gone!

7話しはなしてみよう ／ Let's practice

「〜ばよかった／〜なければよかった」を使っつかって、あなたの後悔こうかいを話しはなしてみよう！

去年きょねんについて、何なにか後悔こうかいしていることはありますか？

Is there anything you regret about last year?

去年きょねん、もっと旅行りょこうに行けいけばよかったと思いおもいます。仕事しごとばかりで、リラックスする時間じかんが少なかっすくなかったです。

I wish I had traveled more last year. I was always working and didn't have much time to relax.

子供こどもの時とき、何なにをもっと練習れんしゅうすればよかったと思いおもいますか？

As a child, what do you think you should have practiced more?

子供こどもの時とき、ピアノをもっと練習れんしゅうすればよかったと思いおもいます。今いまは弾けひけなくて、ちょっと残念ざんねんです。

I wish I had practiced piano more as a child. I can't play now, and that's a bit sad.

旅行りょこうに行っいった時とき、「〜すればよかった」と思っおもったことはありますか？

When you traveled, was there anything you thought "I should have done that"?

日本にほんに行っいった時とき、もっとお寿司すしを食べれたべればよかったと思いおもいました。値段ねだんは安かっやすかったんです。でも、あまり食べたべませんでした。

When I went to Japan, I thought I should have eaten more sushi. It was cheap but I didn't eat much.

最近さいきん「〜なければよかった」と思っおもったことはありますか？

Recently, was there anything you thought "I shouldn't have done that"?

昨日きのう、夜よる遅くおそくにラーメンを食べたべたんですが、食べたべなければよかったと思いおもいました。お腹おなかが痛くいたくなりました。

Yesterday I ate ramen late at night, but I thought I shouldn't have. My stomach hurt.
