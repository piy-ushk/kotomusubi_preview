Chapter 23-2 ・ 中ちゅう上級じょうきゅう Upper-intermediate

〜ても

Even if ~ / No matter ~ ／ 逆接ぎゃくせつの仮定かてい

1意味いみ ／ Meaning

「〜ても」は「たとえAでも、Bする（Bは変わらかわらない）」という意味いみです。
ふつうは「Aだから、Bしない」と思うおもう場面ばめんでも、
Aに関係かんけいなくBする、と言いいいたいときに使いつかいます。
例れい：「雨あめが降っふっても、行きいきます」＝雨あめでも、行くいくのは変わりかわりません。
「もしAでも」「たとえAでも」と同じおなじです。
「何なにを／いつ／誰だれが」などの疑問ぎもん詞し＋〜てもで
「何なにをしても／いつでも／誰だれでも」の意味いみになります。

「〜ても」 means "even if A, B still happens (B doesn't change)."
Use it when you'd expect "because A, then not B," but B happens anyway, regardless of A.
e.g. 「雨が降っても、行きます」= I'll go even if it rains.
With a question word, it means "no matter what / when / who."

4ポイント ／ Key Points

  • 「〜ても」は「予想よそうと反対はんたいの結果けっか」を表すあらわす。
    「Aが起きおきてもBは変わらかわらない」「AなのにB」の意味いみ。
    「〜けど」「〜のに」と似にていますが、まだ起きおきていない（仮定かてい）のことに使いつかいます。

    「〜ても」 means a result opposite to what you'd expect.
    「〜ても」 = hypothetical "even if".
    For real past events, use 「〜けど」 or 「〜のに」.

    仮定かてい：雨あめが降っふっても、行きいきます。
    事実じじつ：雨あめが降っふったけど、行きいきました。

    hypothetical: even if it rains, I'll go
    fact: it rained, but I went

  • 疑問ぎもん詞し ＋ ても＝「no matter ~」。
    「何なにを食べたべても」「誰だれが来きても」「いくら高くたかくても」「いつ行っいっても」など。

    Question word ＋ ても.
    「疑問ぎもん詞し + 〜ても」 = "no matter what/who/when/how much" — very useful pattern.

  • 後ろうしろに命令めいれい・依頼いらい・意志いしOK（ここが「〜ば」と違うちがう）。
    「〜ば」は、後ろうしろに「〜ましょう」「〜てください」などの命令めいれい・依頼いらい・意志いしの文ぶんが使えつかえません。
    「〜ても」にはこのルールがないので、
    「雨あめが降っふっても、行きいきましょう」「遅れおくれても、必ずかならず来きてください」など、自由じゆうに使えつかえます。

    It can be followed by commands, requests, or volitional sentences — this is where it differs from 「〜ば」.
    With 「〜ば」, you cannot use commands, requests, or volitional sentences (「〜ましょう」「〜てください」 etc.) in the second half.
    「〜ても」 has no such rule,
    so you can freely say 「雨が降っても、行きましょう」 (Even if it rains, let's go) or 「遅れても、必ず来てください」 (Even if you're late, please be sure to come).

  • 名詞めいし・な形容けいよう詞しは「でも」。
    「雨あめでも」「暇ひまでも」「学生がくせいでも」のように使いつかいます。

    For nouns and na-adjectives, use 「でも」.
    e.g. 「雨でも」 (even if it rains), 「暇でも」 (even if you're free), 「学生でも」 (even if you're a student).

    ○ 雨あめでも行きいきます。
    × 雨あめても行きいきます。

    ◯ noun ＋ でも: "even if it rains"
    ✗ not ても after a noun

よくあるミスCommon mistakes

× 高いたかいても、買いかいます。
○ 高たかくても、買いかいます。
い形容けいよう詞しは「い」を「く」に変えかえてから「ても」。

For i-adjectives, change 「い」 to 「く」 before 「ても」: 高くても.
