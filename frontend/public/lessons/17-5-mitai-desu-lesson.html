Chapter 17-5 ・ 中ちゅう上級じょうきゅう Upper-intermediate

〜みたいです

Looks like ~ ／ It seems ~ ／ 観察かんさつからの推測すいそく

1意味いみ ／ Meaning

「〜みたいです」は、
自分じぶんが見みたり聞いきいたりした情報じょうほうから推測すいそくするときに使いつかいます。
「あの雲くも、犬いぬみたいだね」のような 「〜のようだ／〜に似にている」
という比喩ひゆ・例えたとえにも使いつかいます。
カジュアルでは「みたい」だけで止めとめてもOK
（「雨あめみたい」「忙しいいそがしいみたい」）。

「〜みたいです」 expresses "it seems / looks like",
based on what you've directly seen, heard, or felt.
Also used for resemblance / metaphor
("that cloud looks like a dog").
Casual: drop 「です」 →
「みたい」.

2文型ぶんけい ／ Sentence Pattern

〜（普通ふつう形けい）＋ みたいです

品詞ひんし接続せつぞくと例れい
動詞どうしverb普通ふつう形けい（短いみじかい形かたち）＋ みたいです降るふる → 降っふったみたいです／しているみたいです
い形容けいよう詞しi-adjそのまま ＋ みたいです忙しいいそがしいみたいです／寒かっさむかったみたいです
な形容けいよう詞しna-adj「だ」をとって ＋ みたいです元気げんきみたいです／静かしずかみたいです
名詞めいしnounそのまま ＋ みたいです学生がくせいみたいです／犬いぬみたいです
part of speechconnection & example
verbplain form (short form) + みたいです (it seems / looks like)降るふる → 降っふったみたいです／しているみたいです
(it seems it rained / it seems they're doing it)
i-adjas is + みたいです (it seems)忙しいいそがしいみたいです／寒かっさむかったみたいです
(seems busy / seems it was cold)
na-adjdrop 「だ」 + みたいです (it seems)元気げんきみたいです／静かしずかみたいです
(seems well / seems quiet)
nounas is + みたいです (it seems / looks like)学生がくせいみたいです／犬いぬみたいです
(seems to be a student / looks like a dog)

4ポイント ／ Key Points

  • 「観察かんさつ → 推測すいそく」がベース。
    目めで見みたり、耳みみで聞いきいたり、手てで触っさわったり ── そういう直接ちょくせつの情報じょうほうから判断はんだんするときに使いつかいます。「噂うわさで聞いきいた」だけの推測すいそくには「〜そうです」（17-1）の方ほうが自然しぜん。

    It's based on "observation → inference".
    Core idea: "observation → inference". Use 「みたい」 when you make a guess based on something you saw, heard, or felt directly.

    道みちがぬれている →「雨あめが降っふったみたい」○（自分じぶんで見みた）

    The road is wet → "It seems it rained" ✓ ― based on what you see

  • 「〜のようだ／〜に似にている」の意味いみでも使えるつかえる。
    「あの雲くも、犬いぬみたい」のように 比喩ひゆ・例えたとえ にも使えつかえます。これは「観察かんさつ」というよりも「似にている」と感じかんじたとき。

    It can also mean "like ~" / "resembles ~".
    Also used for resemblance/metaphor: "that cloud looks like a dog", "he's like a child".

    この絵え、本物ほんものみたいですね。／彼かれは子どもこどもみたい。

    This picture looks like the real thing. ／ He's like a child.

  • 自分じぶんのことにも使えるつかえる。
    自分じぶんの状態じょうたいがはっきり分からわからないときに、客観きゃっかん的てきに「〜したみたい」と言えいえます。

    It can also be used about yourself.
    Also works for yourself when your own situation is unclear: "I seem to have forgotten my wallet."

    財布さいふが見つからみつからない…忘れわすれたみたいです。

    I can't find my wallet… it seems I forgot it.

  • カジュアルでは「です」を省略しょうりゃく。
    友達ともだちとの会話かいわでは 「〜みたい」「〜みたいだね」「〜みたいだよ」 でOK。

    In casual speech, drop the 「です」.
    In casual speech, drop 「です」 → 「みたい」「みたいだね」「みたいだよ」.

    あ、雨あめが降っふってるみたい。／忙しいいそがしいみたいだね。

    Oh, it seems it's raining. ／ You seem busy.

よくあるミスCommon mistakes

× 彼かれは学生がくせいだみたいです。
○ 彼かれは学生がくせいみたいです。
な形容けいよう詞し・名詞めいしのあとに「だ」はつきません。そのまま「みたいです」をつけます。

Don't add 「だ」 after nouns and na-adjectives — attach 「みたいです」 directly: 学生みたいです.

7話しはなしてみよう ／ Let's practice

「〜みたいです」を使っつかって、見みたこと・気づいきづいたことを言っいってみよう！

窓まどの外そとを見みて、今日きょうの天気てんきを「〜みたいです」で言っいってみましょう。

Look outside the window and describe today's weather using 「〜みたいです」.

空そらが暗いくらいですね。雨あめが降るふるみたいです。風かぜも強くつよくなっているみたいです。

The sky is dark. It seems it's about to rain. The wind also seems to be getting stronger.

今いま、近くちかくの人ひとや友達ともだちの様子ようすを見みて、「〜みたいです」で説明せつめいしてみましょう。

Describe someone nearby or a friend using 「〜みたいです」.

友達ともだちは元気げんきがないですね。何なにか心配しんぱいなことがあるみたいです。少しすこし疲れつかれているみたいです。

My friend doesn't look well. It seems they have something to worry about. They seem a bit tired.

あなたの周りまわりで人気にんきのお店みせやレストランについて、「〜みたいです」で話しはなしてみましょう。

Talk about a popular shop or restaurant near you using 「〜みたいです」.

駅前えきまえの新しいあたらしいカフェは、いつも人ひとがたくさん並んならんでいます。すごく人気にんきみたいです。コーヒーが特にとくにおいしいみたいですよ。

There's always a line at the new café near the station. It seems very popular. The coffee seems especially good.

「〜みたい」を使っつかって、何なにかに似にているものを言っいってみましょう。（例れい：あの雲くもは〜みたい）

Use 「〜みたい」 to say something resembles something else (e.g. "that cloud looks like ~").

あの雲くもはうさぎみたいです。小さくちいさくて、耳みみが二ふたつあるみたいに見えみえます。

That cloud looks like a rabbit. It's small, and it looks like it has two ears.
